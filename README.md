# Natural Language Database Interaction with LLMs

AI-powered database query system using Flask, MongoDB and Groq LLaMA.

## Features

- Natural language to MongoDB query conversion
- Groq LLaMA integration
- Flask backend
- MongoDB database interaction
- Dynamic query execution
- Web interface for user interaction

## Tech Stack

- Flask
- MongoDB
- Groq LLaMA
- Python
- HTML/CSS

## Setup

1. Install dependencies

pip install -r requirements.txt

2. Configure .env

3. Run

python app.py
